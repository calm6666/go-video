# go-video 搜索同义词（只挂在查询分析器 go_video_search 上，filter 标记 updateable）
# 格式：UTF-8 无 BOM，Solr synonym 语法，# 开头为注释。
#   A, B, C      等价展开（搜任一个都能召回其余）
#   A, B => C    显式映射（搜 A/B 时按 C 查）
# 生效方式：改这里不需要重建索引，执行 POST /_reload_search_analyzers/<索引或别名> 即可；
# 生产由部署流程滚动 reload，回滚就是把本文件改回上一版再 reload 一次。
#
# 两个必须知道的坑：
# 1. 同义词在**查询侧**展开，无法修正写错的分析器；分词族变更请走递增 SchemaVersion + 重建。
# 2. 停用词也在查询链上：某条同义词的词若全被停用，集群会报 "failed to build synonyms"，
#    因此新增停用词时要顺带检查本表（禁止把等价词指向停用词）。
# 3. Analyzer.Kind = cjk 时中文被切成二元组，整词同义（下面的「up主」）命中率很低；
#    要中文同义词生效请把分词族切到 ik 或 smartcn（并递增 SchemaVersion 重建）。
